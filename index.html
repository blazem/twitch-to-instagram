1. Connect your accounts

Everything runs on this PC. Saved credentials are encrypted for your Windows account. Leave a saved secret blank to keep it.

Twitch

Open Twitch developer apps ↗. Register a Confidential app for yourself. If a redirect is required, use http://localhost. Copy the Client ID and Client Secret below.

Cloudinary · Free plan

Create a free account ↗ or open your console ↗. Select the Free plan; no card is needed. Find your cloud name and API credentials under Settings → API Keys. Only the screenshot you choose to post is uploaded.

Instagram Business

Open Meta developer apps ↗. Set up an app for your own Instagram account, add Instagram, and use its Instagram Login setup to connect your account and generate a token. Allow instagram_business_basic and instagram_business_content_publish. Copy the Instagram account ID and access token here. Meta may require developer registration first.

Advanced

Facebook Login requires a Page-linked Instagram account and a token with instagram_basic, instagram_content_publish and the relevant Page permissions. Use the Instagram account ID, not the Facebook Page ID. Access tokens expire: replace the token here if a connection check fails.

2. Review your screenshot

Open OBS first. This captures the current program scene locally. It does not upload anything. A normal 16:9 scene fits Instagram.

3. Enable your Stream Deck button

In Stream Deck, add System → Open and choose Post to Instagram.vbs from this helper’s folder. Use Open Setup.vbs for an optional second button.

When enabled, the post button uploads your OBS screenshot to Cloudinary and publishes it with your prefix, Twitch title, and suffix. It waits for Instagram’s readiness check and allows one post per Twitch broadcast. The temporary hosted image is removed after successful publication.

There is no publishing button on this setup page. The Stream Deck launcher is the posting action.

No Zapier. No paid plugins. No subscription to this helper. Cloudinary Free usage limits still apply.
